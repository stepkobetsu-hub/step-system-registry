# 講師ポータル ログイン仕様変更記録

- 更新日: 2026-08-27
- 対象システム: 講師ポータル
- 本番URL: https://stepkobetsu-hub.github.io/teacher-portal/
- リポジトリ: https://github.com/stepkobetsu-hub/teacher-portal
- 対象ブランチ: `main`

## 変更内容

### 1. 授業報告のログイン状態を端末に保持

- 一度「授業報告」にログインした講師コードを端末のローカル保存領域に記憶する。
- 自分で「ログアウト」を実行しない限り、次回もログイン状態を継続する。
- ポータルを開き直した場合でも、保存済みの講師コードがあれば自動的に認証処理を行う。
- 「ログイン」ボタンを押す必要がない。

### 2. 講師コード入力時の自動ログイン

- 講師コードを入力すると、ログインボタンを押さなくても自動的にログイン処理を開始する。
- 保存済み講師コードがある場合は入力画面を経由せず自動復帰する。

### 3. ログアウト時のみ保存情報を削除

- 「ログアウト」を押した場合だけ、保存している講師コード・氏名・出退くんQR関連情報を削除する。
- ログアウト後は、次回利用時に改めて講師コードの入力が必要になる。

### 4. 授業報告画面の表示名変更

- `本日の担当コマ数`
- ↓
- `本日の担当コマ数（確認）`

## 実装上の注意

- 実際のパスワードを台帳やGitHubには保存しない。
- 現行の講師ポータルでは講師コードを端末保存し、Apps Script APIで講師情報を確認する方式を維持する。
- 出退くんQR側のログイン保持と授業報告側のログイン保持は同じ講師セッション情報を利用する。
