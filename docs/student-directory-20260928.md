## 主要機能

- 氏名・ひらがな・カタカナ・ローマ字・生徒番号の部分一致検索。候補を選ぶと詳細表示、検索窓は維持。
- 氏名・フリガナ・学年・学校名・保護者連絡先・住所・メール等を表示。項目タップで拡大、電話発信、パスワード項目はタップで確認。
- ☆マスタと時間割マスタを生徒番号で結合し、曜日・時間・科目・コース・備考を表示。
- 口座振替提出（M列）・有効（N列）をチェック式で変更。生徒番号・氏名を含む確認後に保存。
- ☆マスタの確認付き編集、数式セルの変更拒否、保存時の競合確認。
- 選択生徒の面談記録を新しい順に表示し、面談登録へ移動。
- B列空欄は赤い「退塾」、0はオレンジの「退塾予定」、1は在籍表示を省略。
- 「この生徒の成績を見る」を拡大・強調し、生徒名と番号の右側へ配置。左に小型の「★生徒マスタへ」。
