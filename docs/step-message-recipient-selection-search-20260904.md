# STEP配信システム：送信対象選択・氏名検索改善（2026-09-04）

## 対象

- システム：STEP配信システム
- 公開URL：https://stepkobetsu-hub.github.io/step-message-center/
- GitHub：https://github.com/stepkobetsu-hub/step-message-center
- 対象画面：送信対象生徒
- 記録日：2026-09-04

## 1. 選択中の生徒が0人になった場合の「全生徒」自動復帰

### 問題

画面を開いた直後は学年フィルターの「全生徒」が選択されている。
複数の生徒を選択後に「決定」を押すと、候補一覧を絞るため学年フィルターが解除される仕様になっている。
その後、選択済みの生徒をすべて解除して「現在選択中の生徒」が0人になると、学年フィルターも未選択のままとなり、生徒検索欄へ氏名・生徒コード等を入力しても候補が1件も表示されない状態になっていた。

### 改善仕様

送信対象として選択中の生徒が0人になった時点で、学年フィルターを自動的に「全生徒」へ戻す。

対象となる操作：

- 選択済み生徒を個別の「×」で最後の1人まで解除した場合
- 生徒一覧をクリックして最後の1人を解除した場合
- 「全選択解除」を押した場合
- 一覧側の「全解除」で結果として選択人数が0人になった場合
- 「反転」で結果として選択人数が0人になった場合
- 0人の状態で「決定」を押した場合

これにより、選択人数が0人へ戻った後は、アプリ起動時と同じく「全生徒」が選択され、生徒検索をすぐ再開できる。

### 実装

- `selection-reset-fix.js` を追加
- `index.html` から `selection-reset-fix.js?v=20260904-1` を読み込む
- `selected.size === 0` のとき `activeGrades = new Set(['全生徒'])` として学年ボタンを再描画

## 2. 「髙」と「高」を同じ文字として氏名検索

### 問題

生徒マスタ上の氏名が例として「髙木」の場合、検索欄へ一般的な字体の「高木」と入力しても一致せず、生徒が表示されなかった。

### 改善仕様

生徒検索時のみ、異体字の「髙」と常用字体の「高」を同一文字として扱う。
氏名データそのものは変更しない。

例：

- 登録名「髙木」 → 「高木」で検索可能
- 登録名「高橋」 → 「髙橋」で検索可能

既存の以下の検索仕様は維持する。

- 生徒コード
- 漢字氏名
- フリガナ
- ひらがな／カタカナ正規化
- ローマ字検索
- 全角・半角等のNFKC正規化

### 実装

`selection-reset-fix.js` 内で既存の `normalizeStudentSearch_()` を拡張し、正規化後に `髙` を `高` へ統一して検索比較する。
