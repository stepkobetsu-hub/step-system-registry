# 講師初期登録アプリ（2026-09-12）
公開先：[講師初期登録アプリ](https://stepkobetsu-hub.github.io/teacher-portal/registration.html)

資産管理台帳の「講師ポータル」日常利用欄に「講師初期登録アプリ」として掲載。

## 現在の機能
- 新規講師の本人登録と、本人による住所・銀行口座などの後日追加入力・修正。
- 姓・名、フリガナを分けて入力。生年月日はフリガナの直後、メールアドレスの前。住所欄の「あとから入力できます」は削除。
- 銀行入力欄より上の検索ボタンから[銀行DB.jp](https://www.bankdb.jp/)を別タブで開く。入力中のフォームは保持。
- 新規の専用パスワードは4文字以上。数字4桁も受け付ける。
- スタッフ発行コードは7日・1回限り。発行時に本人用QRを表示し、画像保存・リンクコピーが可能。発行済みコードもQR化できる。
- 講師がスマホでQRを読むと、登録ページが開きコードを自動入力。QRはブラウザ内生成で、外部生成サービスへコードを送らない。

## 認証と保存
既存講師は「登録情報を変更」から講師番号と講師マスターAJ列のパスワードでログインする。AJ列に値がある場合はそちらを優先し、既存の他アプリ用パスワードを変更しない。先頭0の4桁にも対応。AJ列が空欄の新規登録者は、本アプリで設定した専用パスワードを使用する。専用パスワードの設定・再設定ではAJ列を変更しない。

保存先は既存の講師マスター（見出し4行目、データ5行目以降）。Aは最大番号＋1、Dは1、Gは登録日時、MはL列の生年月日から年齢算出。銀行はH～K、ゆうちょは9900・5桁記号・種別空欄・最大8桁番号。本人の同じ行だけ更新し、未変更項目とA・D・G・N・Q以降を保持。マイナンバーを再表示しない。認証情報・登録コードの実値は公開記録へ掲載しない。
